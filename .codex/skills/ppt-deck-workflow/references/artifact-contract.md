# Artifact Contract

Current branch note: artifacts are generated by Codex and tracked/exported by `.codex/skills/ppt-deck-workflow/scripts/workflow.py`. Do not use `ppt_workflow.runner` or repository AI provider code.

## Files

`workflow-state.json`

- Tracks topic, audience, page request, research notes, approvals, renderer, render review preference/status, IMG-to-SVG post-export choice/status, execution mode, and final artifacts.
- Tracks per-renderer status under a `renderers` map so `html`, `svg`, and `img` compare outputs can stay in the same run directory without overwriting each other in state.
- This is the source of truth for approval state.

`outline.json`

- Plain JSON outline generated by Codex.
- Keep it renderer-neutral.

`outline-preview.md`

- Human-readable summary for Codex to show the user.

`contents.json`

- Plain mapping from slide title to generated material.
- If titles collide, edit carefully or regenerate with clearer page titles.

`contents-preview.md`

- Human-readable material review file.

`slide-plans.json`

- Contains renderer-neutral slide jobs.
- Shape:

```json
{
  "version": 1,
  "slides": [
    {
      "index": 1,
      "title": "...",
      "material": "...",
      "plan": "...",
      "page_role": "cover"
    }
  ]
}
```

`slide-plans-preview.md`

- Human-readable layout planning review file.

`render-jobs/<renderer>/shared-context.json`

- Shared deck-level context for page subagents.

`render-jobs/<renderer>/slide-xx.json`

- Page-local renderer job files for subagent execution.

`render-jobs/img-svg/slide-xx.json`

- Post-export IMG-to-SVG model job.
- Carries the exact `source_image_path` that must be passed directly to the model, the exact final SVG `target_path`, a `crop_manifest_path`, and the Pillow crop helper path.

`render-jobs/img-svg/slide-xx-crops.json`

- Small deterministic crop manifest used only when the final SVG needs source-image regions for logos, icons, badges, or complex incompatible artwork.
- Uses normalized 1280x720 `[x, y, width, height]` source boxes.
- Is consumed by `scripts/embed_img_crops.py`, which writes Base64 PNG data directly into the final SVG without creating temporary PNG assets.

`img-svg/*.svg`

- One final model-reconstructed, PowerPoint-compatible 1280x720 SVG for every IMG page.
- Keeps text and simple geometry vector.
- May contain embedded Base64 PNG/JPEG `<image>` nodes for source-cropped incompatible regions.
- Must not use a full-slide raster wrapper, external URL/file, `<foreignObject>`, or script.
- Do not create sibling SVG variant directories such as `v1`, `v2`, `overlay`, `image-elements`, or `clean`.

`img-svg-chain.json`

- Records the original IMG PPTX, one-to-one IMG/SVG mapping, native-SVG PPTX, and conversion mode.

## Approval Invariant

The helper enforces:

- no approval for unknown artifacts
- no renderer choice until `slide_plans` is approved
- no export until `slide_plans` is approved
- no `html` or `svg` export until review preference is confirmed
- no `html` or `svg` export with review enabled until the review subflow is marked complete
- no IMG-to-SVG choice until the original IMG PPTX has been exported
- no IMG workflow completion until the user explicitly chooses IMG-to-SVG `off` or `on` after that export
- no native-SVG PPTX export until every model-generated SVG passes the one-to-one, XML, viewBox, embedded-raster safety, and vector-structure checks

Use:

```bash
uv run python -u .codex/skills/ppt-deck-workflow/scripts/workflow.py approve --run-dir output/... --artifact outline
uv run python -u .codex/skills/ppt-deck-workflow/scripts/workflow.py approve --run-dir output/... --artifact contents
uv run python -u .codex/skills/ppt-deck-workflow/scripts/workflow.py approve --run-dir output/... --artifact slide_plans
uv run python -u .codex/skills/ppt-deck-workflow/scripts/workflow.py choose-renderer --run-dir output/... --renderer html
uv run python -u .codex/skills/ppt-deck-workflow/scripts/workflow.py choose-review --run-dir output/... --mode off
uv run python -u .codex/skills/ppt-deck-workflow/scripts/workflow.py complete-review --run-dir output/...
uv run python -u .codex/skills/ppt-deck-workflow/scripts/workflow.py choose-img-svg --run-dir output/... --mode on
uv run python -u .codex/skills/ppt-deck-workflow/scripts/workflow.py complete-img-svg --run-dir output/...
uv run python -u .codex/skills/ppt-deck-workflow/scripts/workflow.py export-img-svg --run-dir output/...
```
