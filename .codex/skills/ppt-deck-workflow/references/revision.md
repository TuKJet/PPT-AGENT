# Revising an existing deck

Read `resume`, the task brief and the current canonical page. Apply the user's correction to the affected content, geometry or style. Persist the accepted end state and preserve other pages, evidence and manual edits. For an annotated screenshot, use the markup to identify the element and the intended change. An artwork correction can span the deck while its example layout belongs to one page. If the existing plan made that layout universal, move it to the intended pages and compose the affected pages around their own evidence.

Only audience-facing words belong in visible copy. A request to redirect an arrow changes the connector in the layout. Record scoped instructions in the task brief and show the helper's canonical preview when approval is needed.
